# Town Clinic – عيادات تاون كلينك

موقع ثابت (ثنائي اللغة عربي / English) لعيادات تاون كلينك.

## الملفات
- `index.html` – الموقع كامل (HTML + CSS + JS).
- `assets/logo.png` – **ضع هنا اللوجو الأصلي كما هو** (اسم الملف لازم يكون `logo.png`).

## التشغيل على GitHub Pages
1. أنشئ ريبوزتري باسم `town-clinic`.
2. ارفع كل الملفات (مع مجلد `assets` واللوجو).
3. Settings ← Pages ← Branch: `main` / root ← Save.
